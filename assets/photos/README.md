# Photos

All people in site photos should be African (patients, doctors, nurses and staff).
Drop JPG files here using these exact names. Until a file exists, the site shows a
labelled placeholder in its place.

| File | What it should show |
|------|---------------------|
| `hero-doctor-patient.jpg` | African doctor consulting an African patient (about 1440x1280, landscape-ish) |
| `home-care-visit.jpg` | African nurse or doctor caring for an African patient at home |
| `dialysis-unit.jpg` | African nurse with an African patient at a dialysis unit |
| `team.jpg` | Your team or African healthcare professionals together (wide, about 2240x960) |

Use photos you own or have a licence for. Compress them (under about 300 KB each).
To add more photos, copy a `<figure class="photo">` block in `index.html`.
